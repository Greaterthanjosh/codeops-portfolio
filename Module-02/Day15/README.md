# Habesha Eatery

A responsive static restaurant website built as the CodeOps Module 2 Day 15 project.

Habesha Eatery is a fictional Ethiopian restaurant located in Bole, Addis Ababa.

## Features

The website includes:

- Sticky responsive navigation bar
- Hero section with call-to-action
- Responsive About/Story section
- Responsive menu cards
- Reservation form
- Footer with address, phone, email, and opening hours
- Keyboard focus styles
- Responsive design for mobile, tablet, and desktop

## Technologies

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS custom properties
- Responsive media queries
- `clamp()` typography
- Semantic HTML

## Responsive Design

The website is designed mobile-first and adapts from approximately 360px mobile screens to wide desktop screens.

The menu uses:

```css
repeat(auto-fit, minmax(250px, 1fr))
```
