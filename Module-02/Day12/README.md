# Habesha Eatery Mini-Site

A two-page accessible mini-site for the fictional Habesha Eatery restaurant in Bole, Addis Ababa.

## Pages

- `index.html` — Reservation page with a reservation form, menu table, food image, and location map.
- `contact.html` — Contact form and opening-hours table.

## How to Open the Site

1. Download or clone this repository.
2. Open the `Day12` folder.
3. Open `index.html` in a web browser.
4. Use the navigation links to move between the Reservations and Contact pages.

The project can also be opened using VS Code and a local development server.

## Accessibility Features

The site includes:

- Semantic HTML elements such as `header`, `nav`, `main`, `section`, `figure`, and `footer`.
- One `h1` heading on each page.
- Descriptive page titles.
- Unique meta descriptions for each page.
- Accessible navigation between both pages.
- Proper `label` elements for every form input.
- Matching `for` and `id` attributes for form labels and controls.
- Required form validation where appropriate.
- Appropriate HTML input types such as `email`, `date`, `time`, and `number`.
- Tables with descriptive captions.
- Table headers using `scope="col"` and `scope="row"`.
- Meaningful alternative text for images.
- A descriptive `title` attribute for the map iframe.
- Forms and navigation that can be operated using the keyboard.
- No dependence on placeholders as form labels.
