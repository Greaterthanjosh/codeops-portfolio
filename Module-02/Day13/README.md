# Bole Brew Café — Business Profile Card

A one-page styled business profile card for Bole Brew Café, a fictional café in Bole, Addis Ababa.

## How to Open

1. Clone or download the repository.
2. Open the `Day13` folder.
3. Open `index.html` in a web browser.

The project can also be opened in VS Code using a local development server.

## Business

**Bole Brew Café**

Location: Bole, Addis Ababa

The fictional café serves Ethiopian coffee, fresh food, and modern café favorites.

## CSS Techniques Used

- CSS custom properties using `:root`
- CSS variables with `var()`
- Global `box-sizing: border-box`
- Google Fonts
- Flexbox for centering the card
- CSS box model
- Padding
- Margin
- Border
- Border radius
- Box shadow
- Typography hierarchy
- Line height
- HSL colors
- Button hover state
- `:focus-visible` for keyboard accessibility
- `::before` pseudo-element
- Responsive media query
- No inline styles
- No IDs used for styling
