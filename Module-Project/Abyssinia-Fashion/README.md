# Abyssinia Fashion

Abyssinia Fashion is a simple fashion e-commerce web application that I built as part of my full-stack development bootcamp.

The idea was to create an online fashion store with an Ethiopian-inspired design and three main categories:

- Women's Fashion
- Men's Fashion
- Baby & Kids Fashion

The project uses HTML, CSS, and JavaScript to create a responsive and interactive shopping experience.

## Features

- Browse fashion products
- View all available products
- Filter products by category
- Search for products
- Add products to the shopping cart
- Remove products from the shopping cart
- Increase the quantity when the same product is added again
- Automatically calculate the cart total
- Save the shopping cart using localStorage
- Restore the shopping cart after refreshing the page
- Checkout form
- Customer name validation
- Ethiopian phone number validation
- Delivery area selection
- Order confirmation
- Clear the cart after a successful order
- Responsive design for desktop, tablet, and mobile screens

## Product Categories

The application currently contains three main product categories:

1. Women's Fashion
2. Men's Fashion
3. Baby & Kids Fashion

There is also an **All Products** option that allows users to return to the complete product collection.
